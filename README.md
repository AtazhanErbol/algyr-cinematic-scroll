# ALGYR — готовый блок на HTML, CSS и JavaScript

Для установки не нужны PHP, Laravel, база данных, Node.js или сборка на сервере. Анимация работает в браузере. Внутри используются локальные GSAP/ScrollTrigger и Lenis; внешних CDN нет. Скриншоты показывают возможности кабинета: это демонстрация, а не работающие курсы, авторизация или личный кабинет.

## Самая простая установка

1. Распакуйте `ALGYR-HTML-Block.zip`.
2. Загрузите **папку `algyr-block` целиком** в публичный корень сайта, рядом с `index.php` или `index.html`. Сохраните её внутреннюю структуру.
3. Удалите старый блок «Барлығы бір платформада» целиком и вставьте на его место:

```html
<div data-algyr-embed data-lang="kk"></div>
<script defer src="/algyr-block/embed.js?v=10"></script>
```

Это также содержимое `paste-this.html`. После публикации очистите кэш страницы в CMS/CDN. В `<head>` сайта должен быть обычный `<meta name="viewport" content="width=device-width, initial-scale=1">`.

Вставляйте код в шаблон или блок «HTML/код», который разрешает `<script>`. Для чистого PHP достаточно вставки в существующий `.php` шаблон. Для WordPress — в шаблон темы или разрешённый блок HTML. Для Laravel — в Blade. Шапку, подвал и стили всего демосайта переносить не нужно.

## Несколько страниц и папки

Тот же код вставляется на любую страницу, где нужен блок. Для всех страниц сразу добавьте его в общий шаблон в нужном месте. Абсолютный путь `/algyr-block/embed.js` работает и на вложенных адресах. Если папка загружена в другое место, например `/assets/algyr-block/`, измените только `src` скрипта — остальные пути определятся автоматически.

На одной странице можно поставить несколько блоков; скрипт подключается один раз. Новые контейнеры после AJAX-навигации также подхватываются автоматически. Поддержан ручной вызов `window.AlgyrEmbed.init(container)`.

Если используются строгие Content Security Policy или настройки CMS, разрешите локальные JS, CSS, шрифты, изображения, запросы к локальным HTML/WebP и необходимый этому виджету inline-style. Если CMS удаляет скрипты, подключите скрипт через штатный механизм темы. Проверяйте через HTTP/HTTPS: открытие `index.html` через `file://` не подходит для загрузки кадров.

## Полная разметка вместо загрузчика

`snippet.kk.html`, `snippet.ru.html`, `snippet.en.html` содержат **всю HTML-разметку блока**, ссылку на CSS и скрипт. Можно скопировать содержимое нужного файла в шаблон или подключить его через PHP `include`. По умолчанию файлы ожидают `/algyr-block/` в корне. Для другого пути замените `/algyr-block/` во всём snippet. Не вставляйте одновременно snippet и короткий код для одного и того же блока.

Этот вариант сохраняет галерею даже без JavaScript. `full-html-example.html` — пример полной вставки. При нескольких полных snippet на одной странице задайте каждому уникальный `id` и соответствующие `aria-labelledby` / `href`.

## Внешний вид и параметры

Шрифты Gotham и Inter, цвета и фон согласованы с текущим ALGYR. Все стили ограничены `.algyr-scroll`, глобального сброса `body`/`html` нет. Скрипт создаёт анимацию только там, где вставлен блок.

```html
<div data-algyr-embed
     data-lang="ru"
     data-header-selector=".header"
     data-pin-top="auto"
     data-scroll-screens="4"
     data-mobile-scroll-screens="3.5"
     data-scrub="0.75"
     data-mask-edge="0.20"></div>
<script defer src="/algyr-block/embed.js?v=10"></script>
```

| Атрибут | Значение | Назначение |
|---|---|---|
| `data-lang` | `kk` / `kz`, `ru`, `en` | Язык заголовков, подписей и кнопок; изображения кабинета остаются казахскими |
| `data-header-selector` | `.header` | Селектор закреплённой шапки; отступ измеряется автоматически |
| `data-pin-top` | `auto` или число | Отступ сверху в пикселях; `0` для страницы без закреплённой шапки |
| `data-scroll-screens` | `4` | Дистанция прокрутки на компьютере, в высотах экрана; допустимо 2.5–4.5 |
| `data-mobile-scroll-screens` | `3.5` | Дистанция на телефоне/сенсорном устройстве |
| `data-scrub` | `0.75` | Плавность догоняющей анимации: 0.5–1 секунды |
| `data-mask-edge` | `0.20` | Мягкий край смены снимков: 0.15–0.25 |
| `data-lenis` | `false` | Отключить инерцию компонента, если её уже реализует сайт |

Для полной HTML-вставки эти настройки находятся в `data-algyr-config`. Переводы короткой вставки — в `algyr-block/templates/{kk,ru,en}.html`.

Не помещайте блок внутрь родителя с `overflow:hidden/auto`, `transform` или отдельной прокруткой. Для pin нужен основной скролл страницы. Размещайте его на уровне остальных секций сайта. Кнопки «Попробовать бесплатно» нет.

## Телефоны и доступность

На телефоне работает тот же сценарий: движение камеры, курсы, смена скриншотов, обратная прокрутка и остановка кадра. Для сенсорных устройств подготовлены кадры 720×405 (около 2 МБ); декодируются максимум 6 одновременно. Скролл пальцем остаётся нативным, Lenis его не перехватывает. Системный видеоплеер не создаётся вообще — отрисовка идёт в Canvas. Широкая версия использует 1280×720.

При системной настройке «Уменьшение движения» показывается последний снимок без анимации. При ошибке загрузки стартовых материалов доступна галерея. Скриншоты можно открыть отдельно в полном размере.

Проверки и их границы описаны в [VALIDATION.md](VALIDATION.md). Браузерная эмуляция не заменяет проверку на физическом телефоне. Перед публикацией на боевом сайте нужна проверка с его реальными сторонними скриптами и шапкой.

## Что загружать

Обязательно: `algyr-block/` целиком. Остальные файлы архива — инструкция, код вставки и демонстрационные страницы. `index.html`, `demo.css`, `nested/` и `full-html-example.html` предназначены для просмотра примеров, не для замены сайта.
