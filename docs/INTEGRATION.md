# Подключение к Laravel-сайту ALGYR

Скопируйте файлы из ALGYR-Block-Integration.zip:
- `config/algyr-scroll.php`
- `resources/views/components/algyr-scroll.blade.php` и `algyr-scroll-screens.blade.php`
- `lang/kk/algyr-platform.php`, `lang/ru/algyr-platform.php`, `lang/en/algyr-platform.php`
- `public/vendor/algyr-scroll/`
- `public/media/algyr/platform/` целиком, включая `frames/`, `frames-mobile/` и `shots-mobile/`
- `public/media/algyr/brand/`

Вместо старого целого `<section id="platform" class="platform">` вставьте:

```blade
<x-algyr-scroll id="platform" />
```

Компонент подключает готовые локальные JS/CSS и шрифты через asset() и @once только на странице с блоком. Node.js, FFmpeg и Python на сервере сайта не нужны. Не переносите routes, .env, конфигурацию приложения и демошаблон. При необходимости очистите кэш представлений и конфигурации Laravel.

## Настройки

Все в `config/algyr-scroll.php`:

| Ключ | По умолчанию | Назначение |
|---|---|---|
| asset_version | 20261012-9 | Версия URL сборки и кадров; увеличивать при замене файлов, чтобы обновился браузерный кэш |
| scroll_screens | 4 | Дополнительная дистанция пина 400vh, допустимо 2.5–4.5 |
| scrub | 0.75 | Сглаживание 0.5–1 секунды |
| mask_edge | 0.20 | Мягкий край 20% ширины, допустимо 0.15–0.25 |
| phases.videoStart | 0.05 | Конец начальной паузы |
| phases.videoEnd | 0.65 | Конец видео, начало перехода в скриншоты |
| phases.screensStart | 0.72 | Первый скриншот полностью виден |
| phases.screensEnd | 0.95 | Конец смены скриншотов |
| sequence | 120, 12fps, 1280×720 | Шаблон URL и параметры кадров; меняются вместе с ассетами |
| mobile_sequence | 120, 12fps, 720×405 | Отдельная мобильная последовательность, кэш до 6 декодированных кадров |
| mobile_scroll_screens | 3.5 | Дистанция пина на телефоне, в стабильных высотах экрана |
| lenis / lenis_lerp | true / 0.12 | Инерция колеса внутри активного блока |
| header_selector | .header, [data-algyr-site-header] | Поиск закреплённой шапки |
| pin_top | auto | Автоотступ по высоте шапки либо число пикселей |
| mobile_breakpoint | 767 | До этой ширины включительно, а также при coarse pointer — облегчённая анимация |

Шкала таймлайна — 0…1. Все переходы линейно управляются скроллом; камера уже присутствует в исходном ролике. Нового масштабирования скриншотов нет. Последний кадр последовательности совпадает с shot-1.webp. Кнопка «Попробовать бесплатно» отсутствует.

## Через Vite

Вместо готового IIFE импортируйте `resources/js/algyr-scroll-entry.js` в точку входа этой страницы. Исходники и lock-файлы есть в полном архиве. Нужны `gsap@3.15.0`, `lenis@1.3.26`; entry подключает CSS и инициализацию. Выводите `<x-algyr-scroll :assets="false" />`. Не подключайте одновременно второй бандл.

Если сайт уже использует Lenis, до инициализации задайте `window.algyrScrollDependencies = { lenis: existingLenis }`. Можно также передать общий gsap и ScrollTrigger. Компонент не уничтожает чужой Lenis и не запускает для него второй RAF. Собственный Lenis работает на десктопе при входе в сцену и внутри неё; начатый жест завершается за границей пина. После завершения жеста вне блока снова действует обычный скролл.

## Локализация и жизненный цикл

Переводы идут через Laravel __() и текущий locale. Для нестандартного кода kz используйте существующее сопоставление с kk или копию словаря kk. Скриншоты остаются исходными казахскими изображениями.

Список скриншотов формируется в PHP в начале Blade; конфигурация передаётся через экранированный data-атрибут. При смене первого снимка обновите также экран в camera-prepared.mp4, затем пересоберите кадры: одного изменения финального f_119.webp недостаточно для всей камеры.

API: `window.AlgyrScroll.initAll(container)`, `mount`, `getInstance`, `destroy`. Поддержаны события algyr:init и livewire:navigated. Повторный init безопасен. Удаление блока освобождает pin, декодированные кадры, обработчики и принадлежащий компоненту Lenis.

CSS ограничен .algyr-scroll. Сохраняйте класс platform: CSS текущего сайта задаёт overflow:hidden другим section. Не оборачивайте закреплённую сцену в контейнер с transform или overflow:hidden.

На мобильном используется тот же таймлайн с облегчёнными кадрами и нативным скроллом пальцем, без собственного Lenis. В альбомном окне ниже 520px подпись находится сбоку. При ошибке стартового кадра/скриншотов или отсутствии Canvas доступна галерея. Reduced motion — только последний снимок. Без JavaScript работает нативный свайп. При смене ширины и завершении загрузки выполняется ScrollTrigger.refresh().


Для сайта без Laravel используйте [автономную HTML-версию](HTML-INTEGRATION.md); её папка и шаблоны уже собраны в `standalone/`.
