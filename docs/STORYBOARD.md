# Сценарий

Один GSAP timeline 0…1 с scrub0.75 и pin400vh. После остановки завершается короткое сглаживание, затем изображение неподвижно.

| Прогресс | Сцена |
|---|---|
| 0–0.05 | Первый кадр: девушка за ноутбуком |
| 0.05–0.65 | Линейная смена кадров камеры 0…119 |
| 0.65–0.72 | Последний кадр → реальный список курсов, проявляются подписи и точки |
| 0.72–0.95 | Главная → урок → результаты → пробные ҰБТ → профиль |
| 0.95–1 | Финальная пауза, далее обычный скролл страницы |

Мягкая маска раскрывает снимки справа налево, край20%. Новый снимок сдвигается с +2.5% к0, старый к−2.5% и затемняется на10%. Размер интерфейса не меняется. Подписи, точки и линия синхронны со скриншотами.

В фазе видео нет подписей разделов кабинета и активных точек. В первом плоском кадре показан именно список курсов. Последний видеокадр и первый скриншот идентичны; на стыке изображение остаётся в том же положении; подпись и индикатор появляются под ним.

Прокрутка вверх обращает тот же timeline и кадры. Для скачка по точке скролл перемещается к соответствующей сцене.

Телефон: обложка и горизонтальный свайп без pin/видео/Lenis. Reduced motion: последний снимок. CTA отсутствует.
